# Searchlight

![Searchlight](/images/blocks/block/searchlight.png)

## Description

Ported from the original mod, this light is designed to look like a searchlight, and creates a long-distance beam of
light that places a light source at the end of its path.

As well as all features from the original mod, you are also able to dye the lights now, as well as the other features
mentioned in the [Light Blocks index](./index).

## Interaction

- **Right-click** (with empty hand): Re-sync/rotate the beam to where you are looking.
- **Debug Beam**: If you are holding a searchlight, you can see where the beam is pointing
- **Dye**: Change the beam color.
- **Glowstone Dust**: Increase brightness.
- **Redstone**: Decrease brightness.
